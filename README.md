## Про проєкт

**Система управління чергою пацієнтів** - це веб-застосунок, який надає змогу зручно менеджити записи пацієнтів на прийом до лікаря, а також слідкувати за чергою на прийом.

### Проблематика

- Нерівномірне навантаження на лікарів;
- Живі черги;
- Відсутність прозорого статусу відстеження статусу черги в реальному часі;
- Непередбачуваність часу очікування для пацієнтів

### Ролі користувачів

| Роль | Опис |
|---|---|
| Адміністратор клініки | Керує лікарями, кабінетами, розкладом |
| Реєстратор | Оформлює запис пацієнтів, видає талони, керує живою чергою |
| Лікар | Переглядає свою чергу, викликає пацієнтів, позначає статус прийому |
| Пацієнт | Записується на прийом, бачить статус своєї черги та орієнтовний час очікування |

### Функціональні вимоги

- **Керування лікарями та їх графіком** - CRUD-операції над лікарями, налаштування робочих днів, графіків прийому лікарів та фіксованої кількості необхідного часу на один прийом.
- **Запис на прийом** - онлайн-записом пацієнтом або реєстратором, а також скасування або перенесення запису.
- **Розрахунок орієнтовного часу очікування** - на основі позиції в черзі, а також виділеного часу прийому одного пацієнта з динамічним оновленням у реальному часі.
- **Табло черги** - відображення поточного та наступних номерів талонів по кабінетах, з підтримкою окремого табло для кожного поверху клініки
- **Автентифікація та розмежування доступу** - окремі можливості для кожної ролі

### Технологічний стек
 
- **Frontend:** React, Redux Toolkit, TanStack Query, Tailwind CSS
- **Backend:** Node.js, Express
- **База даних:** MongoDB
- **Реальний час:** Socket.io
